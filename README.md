# global-sales-powerbi-dashboard
PowerBI dashboard for global sales analysis
📊 Global Sales Performance Dashboard (Power BI)

🚀 Project Overview

This project showcases an interactive Global Sales Performance Dashboard built using Power BI.
It provides insights into revenue, orders, customer behavior, and sales trends across different countries and product lines.

---

📌 Key Features

- 📈 Total Revenue: 10.03M
- 📦 Total Orders: 2.823K
- 💰 Average Order Value: 3.55K
- 🌍 Sales by Country Analysis
- 🚗 Sales by Product Line Analysis
- 📅 Monthly Sales Trend Visualization

🎯 Interactive Elements

- Product Line slicer
- Country slicer
- Dynamic filtering across all visuals

---

🔍 Key Insights

- USA contributes the highest share of total revenue
- Sales peak observed in November (seasonal trend)
- Product categories show relatively balanced performance
